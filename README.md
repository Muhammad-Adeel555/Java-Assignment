# 📊 Student Statistics Program

This Java program analyzes a list of students and their scores to calculate and display basic statistics like average, highest, and lowest scores.

---

## 🧠 Features
- Parses a string of student data (`"Name:Score"` format)
- Calculates:
  - Total number of students
  - Average score
  - Highest score and who achieved it
  - Lowest score and who achieved it
- Displays all results in the console

---

## 🛠 Technologies Used
- Java
- Arrays and string manipulation
- Basic logic and control flow
